# MultiSea launchpad · Base mainnet deploy signer
Static page (index.html + plan.js). Your injected wallet signs each of 24 pre-built txs; the page holds no keys.
- plan.js: generated by `node tools/build-plan.mjs /tmp/lp-plan-base.json` from multichain-dashboard `scripts/lp-mainnet-plan.mjs` output.
- Each send is refused unless the deployer's Base nonce (latest, pending, and wallet) equals the step's expected nonce.
- Tests: `node tools/fork-test.mjs <anvil-fork-url>`, `node tools/browser-test.mjs <anvil-fork-url> <page-url>` (page `?rpc=` override is test-only).
- Do NOT use the deployer for any other tx on Base/Ethereum/BNB/ApeChain/Robinhood until all deploys finish: peers are nonce-predicted.
